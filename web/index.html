系統功能與方法

檢索流程

  1. 文件擷取：預設載入 1,000 篇 GLP-1 相關 PubMed 摘要。可匯入 PubMed 摘要匯出檔（.txt）、上傳 XML，或透過 PMID／PMCID 取得文獻；自動辨識 PubMed／JATS 格式，擷取標題、作者與摘要，並略過沒有摘要的紀錄。
  2. 句子分割：採規則式斷句切分文本，正確處理縮寫與小數點，避免誤判句尾。
  3. 文字正規化：統一大小寫、移除停用詞，並使用 Porter 詞幹還原；數字與單一字母不列入檢索索引。連字號複合詞同時保留完整詞形與拆分詞，提升搜尋涵蓋率。
  4. 索引建置：建立「摘要」與「標題＋摘要」兩套加權反向索引，依「包含標題」選項切換。文件新增後，瀏覽器即時重建索引。
  5. 向量檢索：文件與查詢以相同的權重方法轉成向量，以餘弦相似度（或不正規化時的內積）排序，並支援 * 前綴搜尋。權重可切換 Raw TF、Log TF、Binary × 不用 IDF、ln(N/df)、ln(N/df)+1 × L2 正規化與否。

進階功能

  1. 拼字校正：查詢詞不在語料詞彙中時，以動態規劃計算編輯距離（允許相鄰字元交換），自動改用語料中距離最近、出現最頻繁的字。
  2. 模糊比對：開啟後，每個查詢詞幹也會比對索引中編輯距離 ≤ k 的詞幹，權重乘上 1/(1+距離)。
  3. 命中位置：每筆結果列出關鍵字出現在第幾句（S）、句中第幾個字（W），並區分完全比對與部分比對。
  4. 詞頻分析：以四種前處理條件計算 CF、DF、IDF，繪製 Zipf 分佈並以 log–log 迴歸估計 Zipf exponent；依 DF 與 CF 門檻將詞彙分為高、中、低頻三段，檢驗各段與 Zipf 直線的符合程度。
  5. 詞嵌入：以 Word2Vec（Skip-gram／CBOW）訓練詞向量，內建以預設語料預先訓練的模型，可查詢語意最相近的詞。

權重方法與檢索評估

權重由三個彼此獨立的部分組成：TF（Raw、Log、Binary）、IDF（不使用、ln(N/df)、ln(N/df)+1）與文件向量正規化（L2 → cosine；不正規化 → 內積）。本區使用同一套前處理、同一批查詢與同一份相關性判斷，一次只改變權重方法，並固定關閉拼字校正與模糊比對。

    詞頻分析

    詞頻分佈與 Zipf's Law

    分析目前語料庫（0 篇，標題＋摘要）的詞彙分佈：以四種前處理條件建立詞彙，計算每個詞的 Collection Frequency（CF）、Document Frequency（DF）與 IDF，並檢驗 Zipf's Law——詞的出現次數與排名大致成反比，排名越前面的詞出現越多次。以公式表示為 f(r) ∝ 1 / rk，取對數後 log f(r) = log C − k · log r，因此在 log–log 圖上應接近一條直線，斜率即為 Zipf exponent k（理想值約為 1）。

    前處理與詞彙統計

    1. A　Tokenization + Case folding：以空白切詞並轉成小寫（Data、DATA → data）；標點仍黏在字上，例如 obesity, 與 obesity 是不同的詞。
    2. B　+ 去除標點：data, data. data; → data；保留字中的連字號、撇號與小數點（glp-1、2.5），保留數字與停用詞。
    3. C　+ 移除停用詞：使用與檢索系統相同的停用詞表。
    4. D　+ Porter stemming：以自行實作的 Porter stemmer 進行詞幹還原（純數字不處理）。

    四種前處理條件的比較

    詞彙頻率表（CF／DF／IDF）

    CF = 詞在整個語料中出現的總次數；DF = 包含該詞的文獻數；CF/DF = 平均每篇（有出現的文獻）出現幾次，越大代表越集中在少數文獻；IDF = log10(N / DF)。點擊欄位標題可排序，點擊詞可直接搜尋。

    輸入的詞會依目前的前處理條件轉換成索引詞，例如條件 D 時 patients 會轉成 patient。

    CF–DF 散佈圖

    每個點代表一個詞。虛線為 CF = DF（每篇只出現一次）；離虛線越遠、越往上方的詞，在少數文獻中重複出現越多次。表格目前這一頁的詞以橘色標示。

    區段分析：高頻／中頻／低頻

    依兩個門檻把詞彙分成三段：高頻（太常見）為出現在太多文獻中的詞，低頻（太罕見）為出現次數極少的詞，其餘為中頻（顯著詞）。區段一律依 CF 排名切分：高頻的界線在最後一個 DF 比例超過門檻的詞之後，因此高頻區可能包含少數 DF 未達門檻的詞。主圖勾選「顯示區段界線」可看到同一組界線。

    殘差 = 實際的 log10(CF) 減去迴歸線的預測值。點越貼近 0 的水平線，該段越符合 Zipf 直線；有規律的彎曲代表系統性的偏離。

    詞嵌入

    Word2Vec 詞向量：CBOW 與 Skip-Gram

    以目前語料庫（0 篇）訓練詞向量，讓出現在相似上下文的詞擁有相近的向量。CBOW 以周圍的上下文詞預測中心詞；Skip-Gram 以中心詞預測周圍的上下文詞。兩者皆使用 Negative Sampling、高頻詞次抽樣與動態視窗，視窗不跨越句子邊界。網站已內建以相同參數預先訓練的 CBOW 與 Skip-Gram 模型；調整參數後按「開始訓練」，新模型會加入下方的模型清單，可任選兩個模型比較。
